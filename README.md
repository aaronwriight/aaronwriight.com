## Authoring

See the canonical [Writing and publishing guide](writing/README.md) for the shared Scope for Imagination and Venture workflow, including global entry numbering, guided drafts, reusable source templates, review, publication, images, and newsletters.

Photography collections follow the [photography publishing guide](docs/photography-publishing.md);
scientific plots use the [TidyTuesday handoff](docs/tidytuesday-publishing.txt).
Both workflows keep drafts local and require review before staging public content.
See [connected platforms](docs/connected-platforms.md) for setup and service handoffs.
